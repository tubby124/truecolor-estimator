# SEO growth operating standard

Migrated from the private True Color operating standard (effective Aug 23, priority amendment Aug 31), reconciled with Sep 4 prepared-work sequencing. Current work state is in CURRENT-STATE.md. These rules supersede older multi-page wave suggestions in historical instructions.

- Merchant commerce is the highest-priority Google-growth program; approval/serving and offer/feed/cart/order/consent/fulfilment/tax truth are distinct gates.
- Track organic GSC, AI referral/landing activity, Maps calls/directions, and commercial orders/quotes separately. No blended success score or invented attribution.
- One live organic experiment at a time. Do not bundle title/meta/H1 with body, schema, links, redirects or template changes. Wait 7–14 completed days and finalized GSC before another mutation; the current experiment's stricter named gate applies.
- No city-page expansion. A consolidation requires page-level organic, AI, commercial/backlink and successor-intent evidence. Permanent one-hop intent-matched redirects; remove sources from sitemap/internal links, never city-product to homepage. One family then 14-day observation.
- Existing useful product pages are DEFEND/RECOVERING until evidence supports intervention. A low-GSC page may still earn AI referrals or orders.
- Before page release: finalized 28-day current/prior baseline, query/cannibalization review, AI/referral evidence, commercial limitations, exact hypothesis, single-scope diff, appropriate code review/checks and live readback with next observation date.
- Verify citation page directly; stale search snippets are not a correction target. Name/address/phone/site use the shared business identity. Distinguish request submitted from record published.
- No fabricated local claims, reviews, partnerships, links or pricing. Outreach/GBP publishing requires explicit task authorization; purchases require approval.
- Weekly: read-only four-lane review. Every 14 days: interpret the experiment as positive/inconclusive/negative. Refresh protected-page status monthly with fully paginated evidence.

Record each experiment/opportunity and resulting evidence in the existing repo SEO log/runbook. The Vault stores supporting private evidence, not a second editable queue.
