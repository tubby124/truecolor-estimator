# True Color shop voice and reusable content contract

Prepared September 6, 2026. Draft creative direction; no owner content approval, scheduling or publication is asserted. The local interactive rehearsal uses an original typographic graphic, never a catalog or customer photograph. [Approval pilot](APPROVAL-PILOT.md) controls actual release.

## Sound like someone at the shop

Help the customer describe what they need without making them learn print terminology first. Use a warm, practical voice with contractions and natural “you” and “we.” Anchor the post in an everyday purpose, give one concrete detail, then make replying easy. Keep local references natural: Saskatoon is context, not a keyword to repeat.

Reusable recipe: **customer situation → useful print detail → simple invitation**. Rotate subjects and openings; copying the same template every week will lose the personality. Cleared real work can add specificity only when the associated facts and permission exist.

Avoid empty quality claims, “elevate your brand,” forced humour, manufactured urgency, fabricated customers, invented shop anecdotes, or “another happy client.” Do not imply a synthetic image is a completed job. Do not repeat dated prices or promise timing without current evidence.

## Inputs required for each business

| Input | What the drafter needs | Missing-input behavior |
|---|---|---|
| Identity | Approved business name, location, contact and intended account | Leave a visible draft gap; never infer a destination from a similar name |
| Voice | Owner direction plus approved public examples when available; prohibited phrases | Use a provisional voice, label it for review; never invent quotations from the owner |
| Useful subject | One actual service, product or source-backed event | Ask for a real subject or create a clearly labelled teaching concept |
| Claims | Current source for each price, specification, inclusion and timing promise | Omit unsupported claims; refresh prices before approval |
| Media | Exact media bytes, provenance, social rights, privacy review and final crop | Hold publication; website or Merchant permission is not social permission |
| Customer action | One appropriate way to reply, order or ask for details | Use only a verified business contact; no invented booking promises |
| Release package | Exact caption, final JPEG, verified account and timezone-qualified date | Draft only until the owner approves the complete package |
| Delivery receipts | Approval version, scheduling result, provider result and public readback | Describe only the state supported by receipts; uncertain delivery stops retries |
